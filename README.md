# Derek Chan — Structures & Mechanical Portfolio

Static site (plain HTML/CSS/JS, no build step). To publish on GitHub Pages:

1. Create a new public repository on GitHub (e.g. `portfolio`).
2. Upload the contents of this folder (not the folder itself) to the repository root: `index.html`, `.nojekyll`, `README.md` and `assets/`.
3. In the repository, open **Settings → Pages**, set **Source** to **Deploy from a branch**, branch **main**, folder **/ (root)**, and save.
4. After a minute the site is live at `https://<username>.github.io/<repo>/`. All paths are relative, so it works from that subpath.
